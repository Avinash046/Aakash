# Aakash - AI Personal Assistant (CLI Prototype)

## Features
- Voice & text command recognition
- Stubs for booking, messaging, media, and vision (face/gesture) features

## Setup
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage
```bash
python aakash.py
```

- Type your command or type `voice` to use voice input.
- Type `exit` to quit.

## Extending
- Add real API integrations and expand modules in `modules/`.
- Add multilingual support and advanced AI/ML as needed.
